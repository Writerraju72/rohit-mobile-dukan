# Rohit Mobile Dukan — GitHub Pages Website

Included files:
- `index.html` — premium responsive homepage, bilingual copy, services, location, sticky mobile contact bar, hero exploded-view video and scroll-controlled cinematic video.
- `exploded-view.mp4` — supplied exploded-view video used in the homepage hero.
- `scroll-animation.mp4` — supplied scroll video, driven by scroll position.
- `reference-design.png` — the reference image for your design.

## Publish from your existing GitHub repository
1. Open https://github.com/Writerraju72/rohit-mobile-dukan
2. Tap **Add file → Upload files**.
3. Upload `index.html`, `exploded-view.mp4`, and `scroll-animation.mp4` together to the repository root.
4. Commit changes to `main`.
5. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.

## Before launch
In `index.html`, replace `SHOP_PHONE` and `WHATSAPP_NUMBER` with the shop's real number in digits-only international format, for example `919876543210`. Confirm shop hours and address with the owner. The map link currently searches the supplied location and should be checked for pin accuracy.
