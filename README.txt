Rohit Mobile Dukan — Premium Video Website

FILES:
- index.html — full-screen video hero with text layered over the exploded-view video; second full-bleed scroll-controlled video section with text overlay.
- exploded-view.mp4 — hero background video.
- scroll-animation.mp4 — scroll-scrubbed background video.
- reference-design.png — supplied visual reference (not needed for the website).

UPLOAD:
1. Open https://github.com/Writerraju72/rohit-mobile-dukan
2. Add file > Upload files.
3. Upload index.html, exploded-view.mp4 and scroll-animation.mp4 to the repository root.
4. Commit changes to main.
5. Settings > Pages > Deploy from a branch > main > /(root) > Save.

BEFORE PUBLIC LAUNCH:
Open index.html and set SHOP_PHONE and WHATSAPP_NUMBER to the shop's real phone number in international format using digits only, for example 919876543210. Verify address, shop hours, and all service claims with the owner.
